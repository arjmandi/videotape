# Contrail: the rendered demo

Written by `scripts/report` from each story's dailies.json, the project's ledger.jsonl and dist/. A check's pass rate counts the checks of every kept take by the element they judge; a move's cut, dissolve and seams count as Move.

The failures accepted in each tape, why each fails and what would fix it are in [retry.md](retry.md).

# Guide

`README.md` at the repo root is the developer's guide. It builds Contrail from an empty folder in six parts: start a project with `videotape new contrail`, what a screenplay holds, connect the data, write the screenplay, write the stories, and render, review, fix and publish. It ends with a section, `## The words Videotape uses`, that gives each of the framework's words one meaning. Each file the guide shows whole, in a fence such as ```` ```python title=contrail/data.py ````, is that file of `examples/contrail`, byte for byte. A ```` ```sh ```` block holds commands, one to a line, and a ```` ```text ```` block right after it shows what its last command prints. `tests/test_guide.py` runs the commands in order: first in the project `new` writes, then, from the guide's first whole file on, with `examples/contrail` copied over that project and the stand-in as its model, as the guide's part 2 sets it. The stand-in is made to fail the key of the state the guide retakes, on the render's takes, and of the state it accepts, on every take, so both commands act on a real failure. It films Contrail's other shots clean on the first take, and the starter with its own flaws, as a reader's stand-in does. `scripts/words-test` asks Claude where the help texts and error messages name a concept by another word than the words section gives it, and writes the answer to `words-test.md`.

## Sub-features

- `guide-files` holds each whole file the guide shows to `examples/contrail`, and each non-empty `contrail/*.py` and `stories/*.toml` there to a whole file in the guide.
- `guide-commands` runs the guide's commands in order, each exiting 1 exactly when the output the guide shows has a `fail` line, and printing each line the guide shows, with paths and numbers left open, through `publish`, the guide's last command.
- `guide-player` is the same run with TapePlayer opened by each `play` and quit, behind the `player` marker.
- `words-test` builds the request, counts its tokens, refuses a call over the cap, prices the answer, writes the report and the ledger line, and never shows the key, all proven by `uv run pytest tests/test_words_test.py` with no network.
- `words-no-key` stops without `ANTHROPIC_API_KEY` in the environment or the repo's `.env`, with exit 1, before any request.
- `words-paid` is the paid call. It costs money, and waits for a key and the user's cap.

## How to get to it (user POV)

- Read `README.md` and follow it in an empty folder, from `uvx --from <git URL or checkout> videotape new contrail`.
- From the repo root, run `uv run pytest tests/test_guide.py`.
- Export `ANTHROPIC_API_KEY`, or set it in the repo's `.env`, then run `uv run scripts/words-test --cap-usd 1` from the repo root and read `words-test.md`.

## Gotchas

- `pyproject.toml`'s `addopts` deselects the `player` marker, as it does `qwen`. `-m player` selects it, and also takes over the screen, so never run it without the user's yes.
- The guide's output blocks for the terminal tape's `render` and `retake` come from the test's stand-in, not from a plain one, which passes every shot within four takes and films some on a later take. Driving `retake` or `accept` by hand on the terminal tape prints other lines than the guide's. The starter's render in part 1 is a plain stand-in's, and prints what the guide shows.
- The commands' test copies `examples/contrail` with videotape's path made absolute, so `uv run pyright contrail` and `uv run python -c ...` make their own `.venv` in the copy, from uv's cache. With an empty cache they need the network.
- `uv run` in a project that depends on this checkout rebuilds videotape after any run that wrote new bytecode under `videotape/__pycache__`, because `[tool.uv] cache-keys` lists `videotape/**/*`. The rebuild prints `Building videotape @ file://...` and three more lines on stderr. The guide's blocks leave those lines out.
- `publish` must stay the guide's last command: `test_the_guide_runs_from_new_and_leaves_publish_for_last` fails when a command follows it, or when the guide's first command is not `uvx --from <...> videotape new contrail`.
- `scripts/words-test` reads the help texts from videotape's own parser and the messages from the package's source, so it must run in the repo's environment, through `uv run`. The repo's `.env` is git-ignored.
- The script prices the call at $4 for a million input tokens and $20 for a million output tokens, Anthropic's prices for `claude-opus-5-5` as of 2026-10-06. The estimate takes all 24,000 output tokens the request allows, so the real cost is lower.
